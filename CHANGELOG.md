# Changelog / 更新日志

## [0.1.0] - 2026-10-04

### 中文

- 首个预览版本，支持 QQ、163 和自定义 IMAP over TLS 邮箱。
- 绑定引导、手动刷新、附件分页、多选下载和本页全选。
- 支持中文附件名、同名文件自动编号、增量收信、取消和失败重试。
- 保留原邮件和已读状态；已下载电子书可直接在 KOReader 中打开。
- 提供中英文文档、自动检查、原生模拟器集成测试和版本发布流程。
- 已通过本地 TLS 测试邮箱和 macOS 无窗口原生模拟器测试；真实邮箱、Kindle 真机及手动触控尚未验证。

### English

- First preview release with QQ, 163 and custom IMAP over TLS accounts.
- Account setup, manual refresh, paginated attachments, multiple selection and page selection.
- Chinese attachment filenames, collision-safe filenames, incremental scanning, cancellation and retries.
- Preserves server messages and read state; downloaded books open directly in KOReader.
- Bilingual documentation, automated checks, native emulator integration and version-based releases.
- Tested with a local TLS mailbox and the headless macOS emulator; real providers, physical Kindles and manual touch interaction are not yet verified.
